# P3 internal composition interfaces

Status: proposed; no source implementation or operational endpoint
Owner: factory add-protected-runtime-azure-composition, supporting-docs/composition-boundary.md

This adapter realizes no new neutral contract. The factory packet owns exact
proposed reservation/provisioned deployment forms, later final-scope link,
local-measurement and setup/run retirement profiles/fields/caps. No executable JSON/schema/sample grant is generated here.

| Proposed boundary | Inputs selected by trusted authority | Required output/provenance |
| --- | --- | --- |
| Namespace service | Initialized namespace, accepted parent/path/deployment, one create attempt or same-scope retirement transition | Durable conditional reservation/state receipt; permanent name non-reuse; no direct client overwrite/delete |
| Provider adapter | Exact trusted endpoint/API/kind/ARMID, bounded operation and original generation/operation ref | Authenticated own incarnation/terminal state/dependencies; no tag-based identity or invented ETag deletion |
| Runner capture | Accepted original runner trust/source/phase and closed exact origin/path policy | Frozen private endpoint/bearer capability for existing TokenClient; never worker serialization or token-for-discovery |
| Local trusted worker-host service | Existing actual local launch, file/kernel/namespace roots, selected helper identities and bounded current authority | Real local measurement/finalization/lifecycle; original manager semantics; worker UID excluded |
| Remote evidence bridge | Authenticated independently selected helpers and entire canonical final documents | Closed complete-byte envelope, current scope/two-observer agreement and independent authority derivation; no fake ProcessLaunch |
| Enrollment/issuance | Out-of-band approved setup capability and independently corroborated source/host/role/fingerprint/nonce | Effective bounded returned scope/expiry, separate credential/CA refs and worker denial; requester cannot self-approve |
| External watchdog | Registered exact deployment/envelope/final-scope and authoritative namespace, separate identity/state | Same-operation bounded reconciliation, independent terminal absence/revocation/preservation; no RG/force/retry/reset |
| Selected companion route | Explicit accepted source builder + original three manual inputs and later actual operational authority | Existing hosted admission/full proof/qualification APIs only after current gates; old default still refuses |

All nested runtime I/O remains charged to original phase budgets/deadlines and old
body caps. Independent setup/retirement namespace operations confer no workload
proof authority and cannot refresh a consumed run's budget/grant. A remote envelope
including complete config/policy must fit16KiB; oversized complete input refuses,
not truncate or fetch extra unmetered pages. Actual URLs/keys/IDs are later selected
non-secret references; no ambient loader or generic cloud/plugin registry exists.

Compatibility tests must preserve every old parser/profile, local exact type/PID/
namespace check, neutral observation/proof and report field. Extra cloud evidence
is an independent receipt required by overall deployment acceptance. Passing an
old source/fixture report alone never establishes new remote or deployed origin.

## Closed phase forms and truthful cleanup

The exact grammar belongs to the [reviewed factory boundary](https://github.com/opensoft/openXfactory/blob/c2dfbbcc6fa6965fcde18661bddca1dac7128d47/openspec/changes/add-protected-runtime-azure-composition/supporting-docs/composition-boundary.md).
Reservation freezes complete resource paths/kinds/policies/dependencies/attempts
and forbids unavailable provider/static/full/run facts. Provisioned form adds
only authenticated actual terminal creation/readback and preserves the exact
ordered six-field reservation projection. Neither form contains static/run
commitments. Only the later actual-run link binds independent selection/full
bytes/run/attempt/lease, without a backward hash cycle. The adapter cannot invent
new keys, types or null placeholders outside that factory-owned union.

Setup retirement binds original reservation/setup-cleanup authority before any
P7 link, including partial creation, expiry and predispatch abort. Run retirement
adds actual provisioned/final-scope references. Unknown incarnation/operation
facts remain absent under closed pending/indeterminate result variants; bare404
or a lost response cannot prove a create will not take effect. Complete requires
the exact reserved set and independent preservation/revocation.

Fresh read-only observation authority is separate from original mutation scope.
Late failure can be reported without renewing any permission, lease, Decision,
budget or retry; observing completion after the approved cleanup deadline still
fails qualification. If current observation authority is absent, emission refuses
and missing authenticated evidence fails visibly. Proposed16KiB envelope caps
do not alter the existing larger per-reader caps.
