## Independence and completeness

Each negative starts from an available known-good positive and changes one bound
fact/capability; outage is not worker denial. Use real local crypto/loopback TLS/
kernel/process/SQLite plus authenticated provider/storage doubles. A hostile writer
counterfactual must invalidate exclusivity/retirement acceptance, not pretend a
VM DELETE ETag exists. Per-kind fixtures test VMvmId, diskuniqueId and network own
resourceGuid, explicit detach/dependencies and forbidden retained/shared targets.

Exercise reserved-before-send crash, lost response, pending original LRO, two
concurrent creates/triggers, expired send authority, process death/restart and
permanent name non-reuse after evidence expiry. Namespace/retained runtime ledgers
cannot reset. No raw secret/query/body is retained. Both process cleanup and cloud
retirement are required; independent evidence failure keeps overall incomplete.

Keep every old full/native node ID/static fingerprint/anchor and all original
budgets/deadlines/body limits; add source collection cases only after implementation
and review measured counts. Every owned helper/fixture root/container must be
independently absent at completion while retained/shared controls remain. Source
fakes/real-local primitives do not prove Azure capability or actual administration.

## Later live gates are not source controls

Effective inherited writer/admin exclusions, actual source/image/CA/App/credential
scope, independent initialized namespace/state, real GitHub claims/provider behavior,
watchdog/control-loss and actual absence/revocation/preservation require separate
T013/P4-P8 authorization/readback and T014. Consumer058 T002 and independent human
assurance remain separate. No live negative or mutation probe is authorized here.

Phase controls must include failure/expiry before provisioning completes, after
P5 before dispatch, and after P7 finalization. Forbidden unavailable fields are
absent rather than null/synthetic. Test exact sorted reservation projection and
set equality, case/percent-encoded path aliases, changed ownership/policy/attempt,
and the absence of a backward static/final-link commitment. A current read-only
observer can emit late failure without any mutation; expired observation authority
refuses emission and missing evidence fails qualification. No test may reset an
original cleanup/proof Decision or accept late completion as timely success.
